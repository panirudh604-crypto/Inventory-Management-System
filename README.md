# Inventory-Management-System
A MySQL-based SQL project analyzing inventory, sales, customers, products, orders, and warehouse operations using practical SQL queries and advanced analytical techniques.

## 🛠️ Tools Used :
- MySQL Workbench

## 📊 Dataset Source:

  https://www.kaggle.com/datasets/harshadashirin/inventory-mangement-analysis-sql-based-project

## 🔍 Key Business Questions Answered:

- Which products generate the highest total sales?
- Which customers generate the highest total sales?
- Which product categories generate more than $50,000 in sales?
- Which products have a list price above the average product price?
- How are products ranked based on total sales?

## 📚 What I Learned:

- Applied joins, filtering, sorting, aggregation, and grouping to analyze relational data.
- Used subqueries, CTEs, and window functions for advanced SQL analysis.
- Converted business questions into meaningful SQL-based insights.
